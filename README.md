🧹 SwyNex Internship – Data Cleaning Project

📌 Project Overview

This project was completed as part of my Data Analytics Internship at SwyNex. The main objective of this project was to clean, preprocess, and prepare a raw dataset for further analysis and visualization.

Data cleaning is an important step in the data analytics process because the quality of the input data directly affects the accuracy and reliability of the analysis.

⸻

🎯 Objectives

* Identify and handle missing values
* Remove duplicate records
* Correct inconsistent or invalid data
* Standardize data formats
* Identify and handle outliers where required
* Clean column names and data types
* Prepare the dataset for further analysis
* Create a reliable and structured dataset

⸻

🛠️ Tools & Technologies

* Excel / CSV
* Git & GitHub

⸻

🔄 Data Cleaning Process

The following steps were performed during the project:

1. Data Loading

The raw dataset was imported into Python using Pandas.

2. Data Exploration

The dataset was examined to understand:

* Number of rows and columns
* Data types
* Missing values
* Duplicate records
* Unique values
* Basic statistical information

3. Handling Missing Values

Missing or null values were identified and handled using appropriate techniques depending on the column and its purpose.

4. Removing Duplicates

Duplicate records were identified and removed to avoid inaccurate or repeated information.

5. Data Standardization

Inconsistent values, formats, spellings, and categorical entries were standardized to maintain data consistency.

6. Data Type Correction

Columns were converted to appropriate data types wherever necessary, such as:

* Numerical values
* Dates
* Categorical data
* Text fields

7. Outlier Detection

Potential outliers were examined using statistical methods and visual inspection where applicable.

8. Final Validation

The cleaned dataset was checked again to ensure that the data was consistent, structured, and ready for further analysis.
